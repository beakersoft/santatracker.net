Developer guide

Put Santa on your screen.

SleighWatch is a small, public API for showing Santa’s current journey status in a dashboard, display, website, or festive side project.

Open the API referenceView the live response →

Start with one request

Call this public endpoint. There is no account or API key to set up.

GET https://api.sleighwatch.com/api/santa

The response contains a ready-to-display description and structured information about Santa’s current journey.

Use the description directly

For most displays, the description field is all you need.

const response = await fetch('https://api.sleighwatch.com/api/santa');
const santa = await response.json();

document.querySelector('#santa-status').textContent = santa.description;

Example responses

Before the journey

{
  "description": "Santa is preparing at the North Pole",
  "fromCity": "",
  "toCity": "",
  "country": "",
  "status": "NorthPole"
}

During the journey

{
  "description": "Delivering presents in London, United Kingdom",
  "fromCity": "London",
  "toCity": "",
  "country": "United Kingdom",
  "status": "InFlight"
}

Refresh once a minute

SleighWatch is cached for 60 seconds. Refreshing more often will not give you a newer location, so please configure displays and widgets to update once per minute.
