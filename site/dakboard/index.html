Get set up

Config guide

Add your step-by-step instructions here.

  1. 01

    Before you begin

    Have your Dakboard account setup, and your layout ready to edit.

  2. 02

    Add the widget

    Add a new block to your layout, and pick the External data JSON type (called fetch)

  3. 03

    Configure your display

    Leave the authentication type as 'None', and add the url https://api.sleighwatch.com/api/santa. Give it a few seconds and it should go and grab the fields you can use

    If you want the responses in another language, update the url to include the language code e.g. https://api.sleighwatch.com/api/santa?lang=es-ES (at the minute only english and spanish is supported)

    Once the field come back, just pick the one named description (you can use others but this give a nice bit of location information)

    Set the fetch frequency to a minimum of 5 minutes

  4. 04

    You’re ready to follow Santa!

    If you have any issues please use our feedback link
