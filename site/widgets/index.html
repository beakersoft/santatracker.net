Free embeddable widget

Put Santa on any screen.

A compact, festive status card for your website, dashboard, or DAKboard display. No account, API key, or framework required.

Live preview

Add it to a website

Paste this wherever your site accepts HTML. The versioned URL is recommended for embeds you want to keep stable.

<iframe
  src="https://sleighwatch.com/widget/v1/?lang=en-US"
  title="SleighWatch Santa status"
  width="360"
  height="180"
  frameborder="0">
</iframe>

The widget updates once a minute to match the SleighWatch API cache. Refreshing it more often will not provide a newer location.

Add it to DAKboard

  1. Create or edit a Custom Screen.
  2. Add a Website/iframe block.
  3. Set its URL to https://sleighwatch.com/widget/v1/?lang=en-US.
  4. Resize the block to suit your screen; a 360 × 180 area is a good starting point.

You can also use DAKboard’s Widget block and paste in the website iframe snippet above.

Options

Language

Use lang=en-US or lang=es-ES in the widget URL.

Theme

Use theme=night (default) or theme=light.

https://sleighwatch.com/widget/v1/?lang=es-ES&theme=light

Which URL should I use?

Use /widget/v1/ for an embed that should keep this design and configuration contract. /widget/ is the friendly latest version and will move forward when a future major widget version is released.
